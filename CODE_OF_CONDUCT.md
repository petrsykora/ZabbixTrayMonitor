# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and constructive in issues, pull requests and discussions.
- Focus on the problem, not on the person. Different opinions and experience levels are welcome.
- Harassment, insults, discriminatory or sexualized language, and publishing other people's private information are not acceptable.

## Reporting

If you experience or witness unacceptable behavior, report it to the maintainer [@petrsykora](https://github.com/petrsykora) on GitHub, or use GitHub's **Report content** function on the comment or issue. Reports are handled confidentially.

## Enforcement

The maintainer may edit or remove comments, issues and pull requests, and may block contributors who do not follow this code of conduct, as described in the enforcement guidelines of the Contributor Covenant.
